## Tech Stack

* **Frontend:** HTML, CSS, JavaScript, React, Next.js, Tailwind CSS, Bootstrap
* **Backend:** PHP (Laravel), Python, VB.NET, MySQL, REST API
* **Deployment:** Vercel, Netlify
* **Tools & Workflow:** Git, GitHub, Postman, Figma
* **IoT & Embedded:** C++, Arduino Uno, ESP32

## Menjalankan di Lokal

1. Clone repositori:
   ```bash
   git clone https://github.com
   ```

2. Masuk ke direktori source code:
   ```bash
   cd portofolio/code
   ```

3. Install dependencies dan jalankan development server:
   ```bash
   npm install
   npm run dev
   ```
   *(Jika proyek ini hanya menggunakan HTML/CSS/JS statis tanpa package manager, buka langsung file `index.html` di browser).*
